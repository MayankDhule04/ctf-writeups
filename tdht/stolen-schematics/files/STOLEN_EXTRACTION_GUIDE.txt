TROUBLESHOOTING:
=================================================================

Q: Python script fails with connection timeout
A: Try reducing the timeout or running manual curl commands

Q: All layers return 404
A: The registry state might have changed - try different tags

Q: Script runs but finds nothing
A: The flag might be in the RUNNING container, not registry
   Try exhaustive filesystem search again

Q: "team131-fix" returns 404
A: Tag might have been removed - focus on v1 and other tags
